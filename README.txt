====================================================
 施設利用案内・スケジュール表示ツール（オフライン・単一ファイル版）
====================================================

このindex.htmlを保存してブラウザで開くだけで動きます。
オフライン・単一ファイルで、外部ライブラリは一切使っていません。
公民館・体育館・スポーツセンターなどの「本日の施設利用予定」を、
大型モニター（デジタルサイネージ）に表示するためのツールです。

----------------------------------------------------
■ 使い方の概要
----------------------------------------------------

起動すると「入力・管理画面」が開きます。

・画面左のプール（プリセット）をマウスでつかんで、表の空いている枠に
　ドロップすると、その時間帯に予定が即座に配置されます。
　空いている枠をクリックしても、同様に予定を追加できます。

・配置済みの予定をダブルクリックすると編集モーダルが開き、タイトル・
　補足・時間帯（開始〜終了）・色（背景／文字）を変更できます。
　「イベント名の文字装飾」を有効にすると、1文字ごとにフォントと文字色を
　変えることもできます（すべてOS標準搭載フォントのみを使用しており、
　Webフォントを読み込まないため、オフラインでも表示が崩れません）。

・配置済みの予定ブロックは、そのままドラッグして別の時間帯・別の施設へ
　移動できます（移動先に別の予定があれば上書きされます）。
　予定ブロックの左右の端をつまんでドラッグすると、開始・終了の時間帯を
　変更できます。

・ヘッダー右上のボタンについて
　　🏢 施設を編集 … 表の縦軸（施設名・階数）を追加・削除・変更
　　🏷 プリセットを編集 … よく使う予定名の名称・背景色・文字色を管理
　　　　（左サイドバーの「＋ プリセットを追加」からも同じ画面を開けます）
　　⬇ インポート／⬆ エクスポート … データをJSONファイルとして
　　　　書き出し・読み込み（バックアップや他端末への移行に使えます）
　　📢 告知欄を編集 … 画面最下段の告知欄を編集（下記「告知欄」参照）
　　📋 他の日からコピー … 日付バッジの横のボタン。別の日の予定をコピー
　　表示画面へ ▶ … 大型モニター用のサイネージ画面に切り替え

・サイネージ画面では、今日の日付と現在時刻（時:分、1秒ごとに更新）が
　表示されます。表の下（画面最下段）には告知欄が表示されます。
　画面右下の「⚙」ボタンで管理画面に戻れます。

・左サイドバー下部の「初期状態に戻す」を押すと、施設・プリセット・
　告知欄・すべての予定が、下記CONFIGで指定した初期値に戻ります（確認あり）。

----------------------------------------------------
■ 他の日の予定をコピーする
----------------------------------------------------

新しい日付に予定を作るとき、既存の日の予定をコピーして始められます。

・自動で確認：予定が1件もない日を開くと、コピー確認のウィンドウが
　出ます。「コピーする」で取り込み、「空のまま始める」で白紙から入力
　できます（同じ日は、アプリを開いている間は再度たずねません）。

・手動でコピー：日付バッジの横の「📋 他の日からコピー」から、いつでも
　コピーできます。

・コピー元の選択：予定のある日が、表示中の日に近い順に並びます。
　同じ曜日の日には「★同じ曜日」が付きます。

・すでに予定がある日へコピーする場合は、「空いている枠にだけ追加
　（既存の予定は残す）」か「既存の予定をすべて置き換える」を選べます。
　重なる予定はコピーされません。

・コピーされるのは、施設・時間帯・タイトル・補足・色・1文字ごとの装飾
　です。コピー元に「この日だけの告知欄」がある場合は、告知欄も一緒に
　コピーするか選べます。

・コピー後は、通常の予定と同じようにドラッグ移動・ダブルクリック編集
　ができます。

----------------------------------------------------
■ 告知欄（画面最下段）
----------------------------------------------------

「＊ ○○は一般開放です。　＊　◎は指導員がおります。」のような常設の
お知らせを、表の最下段に帯状で表示します（管理画面・サイネージ画面
の両方）。

・編集方法：管理画面下部の帯（未設定なら「＋ 告知欄を追加・編集」）を
　クリック、またはヘッダーの「📢 告知欄を編集」を押します。

・告知文：複数行入力できます。「＊」「◎」「※」などの記号や全角空白は
　ボタンで挿入できます。

・配色：黄（一般開放）・白・水色・桃色・赤（重要）・紺をワンクリックで
　設定でき、背景色・文字色は個別にも変更できます。

・文字サイズ・配置：小／標準／大、左寄せ／中央から選べます。

・適用範囲：
　　「すべての日で共通」… 毎日同じ告知を出す場合（既定）。
　　「この日だけ」… 休館日のお知らせなど、その日限りの告知。共通設定
　　　より優先されます。「この日の個別設定を解除」で共通設定に戻せます。

・非表示にする：「画面最下段に告知欄を表示する」のチェックを外して
　保存します。「この日だけ」で非表示にすれば、その日だけ消せます。

・編集画面にはプレビューが表示されるので、保存前に見え方を確認できます。

----------------------------------------------------
■ データの保存・バックアップ
----------------------------------------------------

・データは端末のブラウザ（localStorage）に保存されるので、次回開いた
　ときも内容が残ります。ブラウザや端末が変わると引き継がれないため、
　定期的なエクスポートをおすすめします。
　予定・施設・プリセット・告知欄がすべて保存の対象です。
　告知欄が追加される前のバージョンで書き出したJSONも読み込めます
　（その場合、告知欄は非表示・空の状態で読み込まれます）。

----------------------------------------------------
■ カスタマイズしたい場合
----------------------------------------------------

ファイル冒頭の<script>内、CONFIGオブジェクトを編集してください。
施設名、時間帯の区分（既定では「午前／午後①／午後②／夜間」の4区分）、
既定の施設一覧、既定のプリセット（予定名・色）、告知欄の初期値
（DEFAULT_NOTICE：表示／文言／背景色・文字色／文字サイズ／配置）、
初期表示日などをまとめて変更できます。

サンプルとして入っている予定・団体名はすべて架空のものです。
実際の運用前に、ご自身の施設に合わせて書き換えてください。
