# 施設利用案内・スケジュール表示ツール

公民館・体育館・スポーツセンターなどの「本日の施設利用予定」を、大型モニター（デジタルサイネージ）に表示するための、オフライン・単一HTMLファイルのツールです。

> Created for public space digital signage (Free / Standalone Edition)

Notepad などのテキストエディタでも内容を確認できるプレーンテキスト版の説明は [README.txt](./README.txt) をご覧ください。

## 特長

- **単一ファイル・オフライン動作**：`index.html` を保存してブラウザで開くだけ。外部ライブラリ・CDN・Webフォントへの依存は一切なし。
- **ドラッグ＆ドロップで予定を配置**：サイドバーのプリセットを表の枠にドロップするだけで即座に配置。
- **施設 × 時間帯のマス目表示**：施設（行）×時間帯（列、既定は「午前／午後①／午後②／夜間」の4区分）で予定を管理。
- **管理画面 ⇄ サイネージ画面の切り替え**：入力・管理用の画面と、大型モニターにそのまま映せる表示専用画面をワンクリックで切り替え。
- **他の日の予定をコピー**：新しい日付を選ぶと、既存の日の予定をコピーして作り始められます（前日・同じ曜日などの使い回しに便利）。
- **画面最下段の告知欄**：「＊ 黄色の枠は一般開放です」のようなお知らせを、表の下に帯状で表示。文言・配色・文字サイズ・配置を画面から編集できます。
- **ローカル保存＋JSONバックアップ**：ブラウザの `localStorage` に自動保存。エクスポート／インポートでJSONファイルとしてバックアップ・移行が可能。

## 使い方

1. `index.html` を保存し、ブラウザで開きます（サーバー不要）。
2. 起動すると「入力・管理画面」が表示されます。

### 管理画面の操作

| 操作 | 内容 |
|---|---|
| プリセットを枠にドラッグ＆ドロップ | その時間帯に予定を配置 |
| 空いている枠をクリック | 予定の新規追加モーダルを開く |
| 予定をダブルクリック | タイトル・補足・時間帯・色・1文字ごとのフォント/文字色装飾を編集 |
| 予定ブロックをドラッグ | 別の時間帯・別の施設へ移動（重複する予定は上書き） |
| 予定ブロックの左右の端をドラッグ | 開始・終了の時間帯を変更（リサイズ） |
| 日付バッジの ‹ › / 日付クリック | 表示する日付を切り替え。予定が空の日を開くと「他の日の予定をコピーしますか？」と確認が出ます |
| 📋 他の日からコピー | 表示中の日へ、別の日の予定をコピー（コピー元・既存予定の扱いを選択） |
| 告知欄の帯をクリック / 📢 告知欄を編集 | 画面最下段の告知欄を編集（文言・配色・文字サイズ・配置・適用範囲） |
| 🏢 施設を編集 | 表の行（施設名・階数）を追加・削除・並び替え |
| 🏷 プリセットを編集 | 予定名の名称・背景色・文字色を管理 |
| ⬇ インポート / ⬆ エクスポート | データをJSONファイルとして読み込み・書き出し |
| 表示画面へ ▶ | サイネージ（大型モニター）画面に切り替え |
| 初期状態に戻す | 施設・プリセット・告知欄・予定をCONFIGの初期値にリセット（確認あり） |

### 他の日の予定をコピー

新しい日付に予定を作るとき、既存の日の予定をそのままコピーして始められます。

- **自動で確認**：予定が1件もない日を開くと、コピー確認のウィンドウが表示されます。「コピーする」で取り込み、「空のまま始める」でそのまま白紙から入力できます（同じ日は、アプリを開いている間は再度たずねません）。
- **手動でコピー**：日付バッジの横の「📋 他の日からコピー」から、いつでもコピーできます。
- **コピー元の選択**：予定のある日が、表示中の日に近い順に並びます。同じ曜日の日には「★同じ曜日」が付きます。
- **すでに予定がある日へコピーする場合**：「空いている枠にだけ追加（既存の予定は残す）」または「既存の予定をすべて置き換える」を選べます。重なる予定はコピーされません。
- コピーされるのは、施設・時間帯・タイトル・補足・色・1文字ごとの装飾です。コピー元に「この日だけの告知欄」がある場合は、告知欄も一緒にコピーするか選べます。
- コピー後は通常の予定と同じように、ドラッグ移動・ダブルクリック編集ができます。

### 告知欄（画面最下段）

「＊ ○○は一般開放です。　＊　◎は指導員がおります。」のような常設のお知らせを、表の最下段に帯状で表示します（管理画面・サイネージ画面の両方）。

- **編集方法**：管理画面下部の帯（未設定なら「＋ 告知欄を追加・編集」）をクリック、またはヘッダーの「📢 告知欄を編集」を押します。
- **告知文**：複数行入力できます。「＊」「◎」「※」などの記号や全角空白は、ボタンで挿入できます。
- **配色**：黄（一般開放）・白・水色・桃色・赤（重要）・紺をワンクリックで設定でき、背景色・文字色は個別にも変更できます。
- **文字サイズ・配置**：小／標準／大、左寄せ／中央から選べます。
- **適用範囲**：
  - 「すべての日で共通」… 毎日同じ告知を出す場合（既定）。
  - 「この日だけ」… 休館日のお知らせなど、その日限りの告知。共通設定より優先されます。「この日の個別設定を解除」で共通設定に戻せます。
- **非表示にする**：「画面最下段に告知欄を表示する」のチェックを外して保存します。「この日だけ」で非表示にすれば、その日だけ告知欄を消せます。
- 編集画面にはプレビューが表示されるので、保存前に見え方を確認できます。

### サイネージ画面

- 今日の日付と現在時刻（時:分、1秒ごとに更新）を表示。
- 表の下（画面最下段）に告知欄が表示されます。告知欄がある場合は、表全体が収まるよう各行の高さが少し小さくなります。
- 画面右下の「⚙」ボタンで管理画面に戻れます。

## カスタマイズ

`index.html` 冒頭の `<script>` 内にある `CONFIG` オブジェクトを編集することで、以下をまとめて変更できます。

- 施設名（`FACILITY_NAME`）
- 時間帯の区分（`BANDS`）
- 既定の施設一覧（`DEFAULT_FACILITIES`）
- 既定のプリセット（予定名・色）（`DEFAULT_PRESETS`）
- 初期表示日（`DEFAULT_DATE`）
- 告知欄の初期値（`DEFAULT_NOTICE`：表示／文言／背景色・文字色／文字サイズ／配置）

> サンプルとして入っている予定・団体名（例：ちびっこトライアスロンなど）はすべて架空のものです。実際の運用前に、ご自身の施設に合わせて書き換えてください。

## データの保存・バックアップ

予定・施設・プリセット・告知欄はブラウザの `localStorage` に保存されます（端末・ブラウザごと）。ブラウザのキャッシュ削除や端末のトラブルに備え、「⬆ エクスポート」から定期的にJSONファイルとしてバックアップすることを推奨します。「⬇ インポート」で読み込めば、別端末への移行や復元が可能です。

> 告知欄が追加される前のバージョンで書き出したJSONもそのまま読み込めます（その場合、告知欄は非表示・空の状態で読み込まれます）。
