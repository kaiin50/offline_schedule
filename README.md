# 施設利用案内・スケジュール表示ツール

公民館・体育館・スポーツセンターなどの「本日の施設利用予定」を、大型モニター（デジタルサイネージ）に表示するための、オフライン・単一HTMLファイルのツールです。

> Created for public space digital signage (Free / Standalone Edition)

Notepad などのテキストエディタでも内容を確認できるプレーンテキスト版の説明は [README.txt](./README.txt) をご覧ください。

## 特長

- **単一ファイル・オフライン動作**：`index.html` を保存してブラウザで開くだけ。外部ライブラリ・CDN・Webフォントへの依存は一切なし。
- **ドラッグ＆ドロップで予定を配置**：サイドバーのプリセットを表の枠にドロップするだけで即座に配置。
- **施設 × 時間帯のマス目表示**：施設（行）×時間帯（列、既定は「午前／午後①／午後②／夜間」の4区分）で予定を管理。
- **管理画面 ⇄ サイネージ画面の切り替え**：入力・管理用の画面と、大型モニターにそのまま映せる表示専用画面をワンクリックで切り替え。
- **ローカル保存＋JSONバックアップ**：ブラウザの `localStorage` に自動保存。エクスポート／インポートでJSONファイルとしてバックアップ・移行が可能。

## 使い方

1. `index.html` を保存し、ブラウザで開きます（サーバー不要）。
2. 起動すると「入力・管理画面」が表示されます。

### 管理画面の操作

| 操作 | 内容 |
|---|---|
| プリセットを枠にドラッグ＆ドロップ | その時間帯に予定を配置 |
| 空いている枠をクリック | 予定の新規追加モーダルを開く |
| 予定をダブルクリック | タイトル・補足・時間帯・色・1文字ごとのフォント/文字色装飾を編集 |
| 予定ブロックをドラッグ | 別の時間帯・別の施設へ移動（重複する予定は上書き） |
| 予定ブロックの左右の端をドラッグ | 開始・終了の時間帯を変更（リサイズ） |
| 🏢 施設を編集 | 表の行（施設名・階数）を追加・削除・並び替え |
| 🏷 プリセットを編集 | 予定名の名称・背景色・文字色を管理 |
| ⬇ インポート / ⬆ エクスポート | データをJSONファイルとして読み込み・書き出し |
| 表示画面へ ▶ | サイネージ（大型モニター）画面に切り替え |
| 初期状態に戻す | 施設・プリセット・予定をCONFIGの初期値にリセット（確認あり） |

### サイネージ画面

- 今日の日付と現在時刻（時:分、1秒ごとに更新）を表示。
- 画面左下の「⚙」ボタンで管理画面に戻れます。

## カスタマイズ

`index.html` 冒頭の `<script>` 内にある `CONFIG` オブジェクトを編集することで、以下をまとめて変更できます。

- 施設名（`FACILITY_NAME`）
- 時間帯の区分（`BANDS`）
- 既定の施設一覧（`DEFAULT_FACILITIES`）
- 既定のプリセット（予定名・色）（`DEFAULT_PRESETS`）
- 初期表示日（`DEFAULT_DATE`）

> サンプルとして入っている予定・団体名（例：ちびっこトライアスロンなど）はすべて架空のものです。実際の運用前に、ご自身の施設に合わせて書き換えてください。

## データの保存・バックアップ

予定・施設・プリセットはブラウザの `localStorage` に保存されます（端末・ブラウザごと）。ブラウザのキャッシュ削除や端末のトラブルに備え、「⬆ エクスポート」から定期的にJSONファイルとしてバックアップすることを推奨します。「⬇ インポート」で読み込めば、別端末への移行や復元が可能です。
